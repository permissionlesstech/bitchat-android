# Kotlin Android Skill

## Style & Conventions
- Use standard official Kotlin coding style with 4-space indentation.
- Immutability by default: use `val` instead of `var`, `StateFlow` instead of `MutableStateFlow` publicly.
- Use Kotlin Coroutines (`suspend`, `withContext(Dispatchers.IO)`, `SupervisorJob`) for asynchronous tasks.
- Clean extensions, data classes, sealed interfaces/classes for state modeling.
