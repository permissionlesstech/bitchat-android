# Git Workflow Skill

## Commit & PR Rules
- Imperative short commit subjects or Conventional Commits (e.g., `fix(wifi-aware): ...`).
- Keep upstream BitChat commits clean and separable from custom campus-mesh-chat features.
- Never commit keystores, secrets, tokens, or personal identifiers.
- PRs must explain risk, reference issue IDs, and provide test evidence.
